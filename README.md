# uw-imap / libc-client RPMs for AlmaLinux 9

This repository provides `uw-imap` and `libc-client` RPM packages for AlmaLinux 9.

These packages were rebuilt for an EL9 environment using `mock`, based on the EL8 `uw-imap` source RPM. The main purpose is to provide the `libc-client` runtime and development files required by software that depends on UW IMAP, such as PHP IMAP support.

The `uw-imap-devel` package includes the required header and library files, including:

```text
/usr/include/imap/c-client.h
/usr/lib64/libc-client.so
```

The build produces RPM packages such as `libc-client`, `uw-imap`, `uw-imap-devel`, `uw-imap-static`, and `uw-imap-utils`. Debug packages may also be generated by the build process.

The build environment was:

```text
Target distribution: AlmaLinux 9 / EL9
Source package:      EL8 uw-imap SRPM
Build tool:          mock
Architecture:        x86_64
```

To install the locally built packages:

```bash
dnf install ./libc-client-*.rpm ./uw-imap-*.rpm
```

For PHP IMAP builds, install at least the runtime and development packages:

```bash
dnf install ./libc-client-*.rpm ./uw-imap-devel-*.rpm
```

When building PHP with IMAP support, the following options are typically used:

```bash
--with-imap=/usr --with-imap-ssl
```

These packages are provided for compatibility and build purposes. Please review, test, and validate them in your own environment before using them in production.
